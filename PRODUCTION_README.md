# Erce Explorer 🚀

A premium AI-powered discovery platform designed to intelligently organize and present information related to fashion labels, textile design, and educational research.

## Features
- **AI Smart Search**: Powered by Gemini 3 Flash for semantic understanding and real-time insights.
- **Bento Grid Layout**: A modern, responsive interface for entity discovery.
- **Luxury UI/UX**: Cinematic animations, glassmorphism, and premium typography inspired by brands like Apple and Linear.
- **Categorization**: Dynamically filter through Fashion, Streetwear, Textiles, and Research.
- **Responsive Design**: Optimized for mobile, tablet, and desktop viewing.

## Tech Stack
- **Framework**: React 19 + Vite (Next.js-ready architecture)
- **Styling**: Tailwind CSS 4.0
- **Animations**: Framer Motion
- **AI**: Google Gemini API (@google/genai)
- **Deployment**: Vercel-ready with `vercel.json`

## Deployment to Vercel
1. Connect your GitHub repository to Vercel.
2. Ensure the following Environment Variables are set:
   - `GEMINI_API_KEY`: Your Google AI Studio API key.
3. Vercel will automatically detect the Vite project and deploy.

## Backend Setup (Firebase)
1. Complete the Firebase setup in the AI Studio sidebar.
2. Once configured, your Firestore database will power real-time entity updates and cached AI insights.
